About Me

기능을 만드는 데서 끝나지 않고,
데이터 흐름과 위험을 함께 봅니다.

Spring Boot와 React로 서비스를 구현하며 인증·인가, 입력 검증, 공개 범위와 같은 보안 경계를 고민해 왔습니다. 이후 PortSwigger와 워게임을 통해 웹 취약점뿐 아니라 버퍼 오버플로우, 카나리, NX·PIE, ROP 등 시스템 보안 영역까지 학습하고 있습니다.

제조기업 IT 부서 현장실습에서는 사내 인프라 구조를 파악하고 잠재적인 보안 위험 지점을 발견해 외부 권고와 연결한 개선안을 제시했습니다. 동시에 생산실적·태그·QR 데이터를 연계한 생산관리 데이터 기반 이상징후 실시간 자동탐지 시스템을 기획·개발하여 실제 업무에 적용했습니다.

01

문제부터 정의합니다.

코드를 작성하기 전에 현장 업무 흐름, 데이터 생성 지점, 정상·비정상 기준을 먼저 분석합니다.

02

원인을 추적할 수 있게 만듭니다.

탐지 결과만 보여주지 않고 수집 단계, 판정 근거, 오류 로그를 남겨 검증 가능한 시스템을 지향합니다.

03

공격과 방어를 함께 이해합니다.

취약점 재현을 통해 구조적 원인을 이해하고, 실제 서비스와 인프라에 적용 가능한 방어 방법을 고민합니다.
